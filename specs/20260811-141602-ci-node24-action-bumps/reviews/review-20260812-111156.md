R001's syntax fix is correct and was verified against the actual grammar: `Gem::Requirement.new("8")`
compiles to `= 8` and is satisfied by `Gem::Version.new("8")`, `"8.0"`, and `"8.0.0"`, where the
shipped `"8.x"` compiled to `= 8.x` and was satisfied by nothing. R002 is closed with
`digest-mismatch: warn`, confirmed an allowed value by reading `inputs.digest-mismatch` at
`actions/download-artifact@v8` ("Options: ignore, info, warn, error"). R003 is closed across all
three artifacts.

**The re-review's own finding: the corrected `ignore:` block is inert, and not for a syntax reason.**
Checking the newest published major of each action turned up that `main` now sits on the newest major
of *every* action in both workflows — `checkout@v7`, `setup-node@v7`, `upload-artifact@v7`,
`download-artifact@v8`, `pnpm/action-setup@v6`, `gh-release@v3`, `rust-cache@v2`. Every version named
in `ignore:` is a version the repo already runs, and Dependabot only proposes upgrades. So the block
declines nothing that could be proposed. Fixing the syntax was still right — it is a latent bug that
bites the moment anyone adds an entry or reverts a pin — but a block that reads as live protection
while providing none is the exact failure this whole feature is about, so `.github/dependabot.yml` now
says so in its first paragraph, and says why the entries are kept anyway: revert `download-artifact`
to v7 without them and Dependabot re-proposes v8 within the week, exactly as it did the first time.

**US3 is delivered, and by a route worth naming.** Its goal was "a future runtime deprecation surfaces
as a dependency PR rather than as an annotation nobody reads." PR #28 is emphatic proof that it does —
it arrived 64 seconds after the config landed. The `ignore:` block was never what delivered US3; it
was a refinement on top, and it is that refinement which failed and is now moot. The last review
scored US3 as not delivered. That was too harsh on the story and not harsh enough on the refinement;
this report corrects both directions.

All four constitution gates are green on the fixed tree: **62 Rust tests, 47 frontend tests, `cargo
clippy -- -D warnings` clean, `actionlint` exit 0.** All three YAML files parse. 20 `uses:` lines,
