> ## Dependabot ignores made functional; four pins moved past the evaluated set — 2026-08-12
>
> Nothing user-visible. A correction to the entry below, which describes pins that `main` no longer
> carries.
>
> - **The `ignore:` block in `.github/dependabot.yml` never worked.** It shipped with
>   `versions: ["8.x"]`-style entries — the npm and NuGet wildcard spelling. The `github-actions`
>   ecosystem parses `versions:` as a Gem requirement, and RubyGems accepts `8.x` as a legal *version*
>   rather than a range, so each entry compiled to the equality `= 8.x` and matched nothing. All four
>   entries are now bare integers.
> - **It was caught the hard way.** Dependabot opened PR #28 64 seconds after the file landed on `main`,
>   proposing all four majors the file listed as declined, and it merged on a green CI check.
> - **Only one of the four had a real effect.** `download-artifact@v8` changed the default for
>   `digest-mismatch` from a logged warning to a hard failure. The `release` job now passes
>   `digest-mismatch: warn` explicitly.
> - **There is no local check for any of this.** The only signal is on Dependabot's side.
